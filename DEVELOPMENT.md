# Dual-subscription development status

This is a development fork, not a verified live subscription integration.
Native Claude passthrough is opt-in with `CCP_ALIAS_PROVIDER=anthropic`.
See [setup and limitations](docs/src/content/docs/providers/anthropic.md).

## Scope and provenance

- Base: raine/claude-code-proxy `2e2975aee754fff176765bcc2f3e582a79191751`, v0.1.45.
- Adapted passthrough: Sören Nikolaus, PR #133, `f9084b283d5f7681b023bd40f7662659eae2f337`.
- Original MIT license and Git history retained; local `upstream` remote points to raine/claude-code-proxy.
- No Anthropic credential store, login implementation, keychain reads, or shared Codex CLI credential changes.
- Production native endpoint is fixed; redirect following is disabled.
- Native model selection takes precedence over session affinity and auto-review overrides.
- Non-Anthropic dispatch discards client HTTP headers and query strings.
- Native signed thinking stays intact. Foreign visible summaries become text; signatures are never fabricated.

## Validation boundary

Tests use loopback mock servers and synthetic credentials. No live subscription
requests were made. No proxy was installed into the normal environment, and no
existing Claude settings were changed. Test configuration and downloaded Rust
toolchains are outside the repository, inside the task workspace.

Required checks: `cargo fmt --all -- --check`, `cargo clippy --all-targets --locked -- -D warnings`,
`cargo build --all --locked`, and `cargo test --all --locked`.

On 2026-10-14, the full Linux/WSL suite passed **1,136 tests, zero failures**,
including eight Anthropic integration tests. Coverage includes routing and
same-session switching, authentication isolation, native 401/429 responses,
redirect rejection, delayed streaming and cancellation, token counting, unknown
fields, native schema validation, signed thinking and foreign reasoning history.
The existing Codex, Kimi, Grok, Cursor, OpenCode, monitor and CLI tests are retained.
Formatting, strict all-target Clippy (`-D warnings`), and the standalone locked
build also passed. Rust 1.99 compatibility annotations are narrowly scoped
to an existing atomic API rename and redundant attributes generated by async-trait.

Windows native compilation initially failed because the MSVC linker was missing.
Linux/WSL is used for validation; this does not certify a Windows build.

Switch only after a completed tool-use turn. Account access, upstream history
validation, token refresh, and live model switching still require separately
approved live testing. Non-Claude routing is not officially supported by Anthropic.

## Distribution and documentation

No fork releases or hosted documentation are published. Use the Linux/WSL source-build instructions in [README.md](README.md). The binary name remains `claude-code-proxy`.

To validate docs: `cd docs`, `bun install --frozen-lockfile`, `bun run build`, then `bun run check:links`. `bun run dev` starts the local preview. Documentation CI is build-only.

Inherited LRU advisories remain unresolved; see [DEPENDENCY-REVIEW.md](DEPENDENCY-REVIEW.md).
